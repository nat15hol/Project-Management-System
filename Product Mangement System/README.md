# Project Management System

## Description
This is a simple console-based Product Management System built in C#.  
It allows users to add, view, search, delete, and analyze products stored in memory and saved to file.

Each product follows the format:

NAME-NUMBER


Example:

ABC-300


---

## Features

- Add products with validation
- View all products (sorted)
- Search products by name or number
- Delete products
- Statistics section:
  - Total products
  - Highest product number
  - Lowest product number
  - Average product number
- Save products to a local data folder with timestamp

---

## How to Run

1. Open the solution in Visual Studio
2. Build the project
3. Run the program
4. Use the menu to interact with the system

---

## Data Storage

All saved products are stored in a folder called:


data/


Each save creates a new file with a timestamp, for example:


products_2026-05-08_14-30-12.txt
