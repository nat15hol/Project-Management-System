# Project Management System

This repository contains multiple C# console applications:

## Projects

### Project List Manager
A system for managing a list of projects or items.

### Product Management System
A system for managing products with validation, search, delete, and statistics.

---

## Structure

- Project List Manager/
- Product Management System/

---

## How to run

Open each project in Visual Studio and run the corresponding `.csproj` file.
