# Project List Manager

## Description
This project is a simple console application for managing a list of products/cars.  
The user can add items, validate input, and view sorted results.

## How to Use
1. Run the program
2. Enter a product name or car brand
3. Follow the format rules (e.g. ABC-123)
4. Type `exit` to finish input
5. The program will display unsorted and sorted lists

## Features
- Input validation using regex
- Sorting of items
- Console-based menu/input system
